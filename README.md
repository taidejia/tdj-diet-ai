# TDJ AI 餐盤教練 1.7.8
多照片＋外食精準估算版。

- 同一餐一次可上傳最多 5 張照片
- 自動判斷重複角度，避免同一盤重複計算
- 不同盤、飲料、湯、小菜合併成一餐
- 先拆食材與份量，再估中心值與合理熱量範圍
- 外食油脂、醬汁、勾芡納入不確定性
- 文字重量/營養標示優先，用來縮小範圍
- 本餐後今日累計與剩餘額度由程式計算


## 1.7.1
- 修正 meal.html Jinja 區塊結構錯誤。
- 修正多照片前端驗證仍尋找舊 photo 欄位的問題。
- 修正今日累計與剩餘欄位名稱對應。

## 1.7.2
- 修正 1.7.1 template 與舊 app.py 混用造成 calories_estimate Undefined。
- 蔬菜少於 0.5 拳一律顯示 0 拳；零星蔥蒜香菜/醬汁碎菜不計。
- 蔬菜以 0.5 拳為顯示級距。
- P/C/F 與中心熱量差異過大時交叉校正。
- 下一餐由 Python 依真正剩餘 kcal/P/C/F 計算，不得超額。
- 脂肪剩餘很低時，下一餐自動轉為低脂建議。
- 已吃完且飽足度高時，不要求立刻補吃。
- 前台版本字樣更新為 1.7.2。

## 1.7.3
- 拆解食材熱量改為互斥，避免同一份燴汁／油脂重複計算。
- components 加總與整餐合理範圍做一致性檢查。
- 牛三寶、牛腩、控肉、滷肉、五花肉等外食主菜不再過度採最低份量。
- 照片無法確認重量時，以常見外食中位份量作中心估值，合理範圍保留不確定性。
- 前台版本字樣更新為 1.7.3。


## 1.7.5
- 今日整體營養判斷改為體態管理邏輯，不再把所有未吃滿的營養素一律標成「不足」。
- 蛋白質與蔬菜屬主動補足目標；碳水與脂肪以配置空間/上限邏輯判斷。
- 脂肪 38/48g 類似情況會顯示「已接近今日建議量」，不再叫使用者補脂肪。
- 碳水在合理區間時顯示「目前可接受」，不要求刻意吃滿每日碳水。
- 下一餐建議直接讀取今日整體缺口與剩餘額度。
- 下一餐優先補蛋白質與蔬菜，脂肪接近上限時自動轉為低脂安排。
- 今日蔬菜量改為累計所有餐點的拳數。

## 1.7.5.1
- 修正餐點分析成功後，儲存「今日整體營養進度」時的資料格式錯誤。
- daily_progress 新版 dict 格式與舊 list 格式都可相容。
- 修正 `AttributeError: 'str' object has no attribute 'get'`。

## 1.7.6
- AI 回覆去重：overall / good / advice 各自只負責一件事。
- 移除 good 內重複附加全天蛋白質缺口的舊程式邏輯。
- 今日整體營養進度只保留新版 dict 邏輯，不再同時跑舊 list 邏輯。
- 「現在最值得做的一件事」縮成單一動作。
- 「下一餐怎麼安排」改為真人體態教練式文字，減少不必要數字。
- 「中心估值」改為「本餐記錄」，避免照片估算看起來像精準量測。

## 1.7.7
- 完整檢查首頁、單餐分析、今日累計、歷史紀錄與飲水流程。
- 頂部改為「今日整體狀態」：熱量、蛋白質、碳水、脂肪、蔬菜一次看，不再把「還可吃多少」當主視覺。
- 碳水未達每日配置不再一律標「偏少」，改為「尚有配置空間」。
- 修正今日蔬菜累計欄位名稱不一致，避免前餐蔬菜被漏算。
- 每日飲水預設改為體重×40 ml，既有未自訂的會員會自動更新。
- 修改基本資料時保留原本選項與自訂飲水量，不再被預設值覆蓋。
- 文字分析與照片分析會顯示正確來源標籤。
- 今日剩餘改為「熱量參考空間」，營養缺口交由整體進度判斷，避免誤導成全部要吃滿。
- 下一餐建議改成更自然的體態陪跑說法。
- 最近紀錄改成可展開完整分析，減少頁面過長。
- 新增飲水紀錄刪除。
- 修正刪除餐點重複 close/commit 的程式瑕疵。


## 1.7.8
- 單餐判斷與全天進度徹底分離：單餐 status 只描述本餐結構。
- 「澱粉明顯偏多」改為「主食比例較高」，避免與全天碳水配置混淆。
- 全天蛋白質與蔬菜進度依早餐／午餐／晚餐調整語氣，不再用同一門檻判整天。
- 脂肪接近上限時改用「已接近今日建議量／優先低油料理」的陪跑說法。
- 下一餐建議加入可直接照做的食物例子，並受真正剩餘額度限制。
- 沒有明顯優點時不再硬顯示「做得好的地方」。
- 首頁／分析頁會依今天最後一個餐別顯示較合理的全天進度。
- 保留 1.7.7 的多照片、蔬菜累計、體重×40ml飲水、刪除紀錄與防重複送出修正。

## 1.7.9（全介面文字與邏輯稽核）
- 最近紀錄與管理後台移除 P/C/F 縮寫，全部改成蛋白質／碳水／脂肪。
- 下一餐建議改成可直接理解的食物與份量（掌心、拳頭），不再只寫抽象的「一份蛋白質主菜」。
- 修正「茶葉蛋白」錯字與「堅果大量攝取」等不自然文字。
- 單餐狀態與全天狀態用詞再次統一。
- 沒有真正優點時不強制顯示稱讚。
- 分析頁區塊名稱改成更口語、減少重複與額度感。
- 前台、最近紀錄、後台、AI prompt 全部清查縮寫與殘留舊文案。

- 熱量與三大營養素加入一致性校正。

- 歷史餐點只保存當餐分析，不再保存會隨時間過期的今日剩餘、全天進度與下一餐建議。
