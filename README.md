# TDJ AI 餐盤教練 1.7.3
多照片＋外食精準估算版。

- 同一餐一次可上傳最多 5 張照片
- 自動判斷重複角度，避免同一盤重複計算
- 不同盤、飲料、湯、小菜合併成一餐
- 先拆食材與份量，再估中心值與合理熱量範圍
- 外食油脂、醬汁、勾芡納入不確定性
- 文字重量/營養標示優先，用來縮小範圍
- 本餐後今日累計與剩餘額度由程式計算


## 1.7.1
- 修正 meal.html Jinja 區塊結構錯誤。
- 修正多照片前端驗證仍尋找舊 photo 欄位的問題。
- 修正今日累計與剩餘欄位名稱對應。

## 1.7.2
- 修正 1.7.1 template 與舊 app.py 混用造成 calories_estimate Undefined。
- 蔬菜少於 0.5 拳一律顯示 0 拳；零星蔥蒜香菜/醬汁碎菜不計。
- 蔬菜以 0.5 拳為顯示級距。
- P/C/F 與中心熱量差異過大時交叉校正。
- 下一餐由 Python 依真正剩餘 kcal/P/C/F 計算，不得超額。
- 脂肪剩餘很低時，下一餐自動轉為低脂建議。
- 已吃完且飽足度高時，不要求立刻補吃。
- 前台版本字樣更新為 1.7.2。

## 1.7.3
- 拆解食材熱量改為互斥，避免同一份燴汁／油脂重複計算。
- components 加總與整餐合理範圍做一致性檢查。
- 牛三寶、牛腩、控肉、滷肉、五花肉等外食主菜不再過度採最低份量。
- 照片無法確認重量時，以常見外食中位份量作中心估值，合理範圍保留不確定性。
- 前台版本字樣更新為 1.7.3。
