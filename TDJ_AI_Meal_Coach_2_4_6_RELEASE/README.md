# TDJ AI 餐盤教練 2.4.4 RELEASE

## 本版更新
- 總管理後台「學員管理」改為依歸屬下拉分組。
- TDJ 直營固定第一組。

- 有效／未開通／已到期／已停用／全部篩選保留；各分組人數會依目前篩選條件更新。
- 2.4.3 的後台今日飲水與期間平均飲水追蹤完整保留。

## 2.4.6 脂肪判斷優化
- 單餐脂肪較高不再直接等同於「吃得太油」。
- AI 區分食物本身脂肪、烹調油脂、混合與無法確定。
- 鯖魚、鮭魚、蛋、堅果等食材脂肪不再自動被描述為烹調過油。
- 只有炸物、麻油、三杯、明顯油煎/大量炒油或濃厚油醬等有足夠證據時，才提示烹調油脂。
- 全天脂肪累積判斷維持原有每日目標邏輯。
