# TDJ AI 餐盤教練 2.0.4

以 2.0.3 RELEASE 為底，只調整「四種體態目標計算」與「下一餐/外食指南分工」，保留既有 LINE Login、餐點紀錄、照片/文字分析、飲水、歷史紀錄、後台等功能。

## 2.0.4 核心更新

1. **四種目標真正分流**
   - 減重：較明確熱量赤字，以體重下降為主。
   - 減脂：溫和至中度熱量赤字，蛋白質高於單純減重，優先保留肌肉。
   - 維持體重：接近 TDEE，不刻意製造赤字。
   - 增肌改善體態：蛋白質較高；有規律運動才小幅增加熱量，沒有運動時先接近維持量。

2. **每日熱量來源透明化**
   - 顯示估算 BMR、TDEE、目前體態目標與每日建議熱量。
   - 減重/減脂會顯示已納入的赤字比例。

3. **下一餐策略與外食指南不再重複**
   - 「今天接下來怎麼吃｜策略」只講下一餐優先方向。
   - 「外食下一餐指南」才分超商、自助餐/便當、滷味/鹽水雞、火鍋、麵店等逐段列出實際選法。

4. **下一餐會同時看**
   - 使用者目標
   - 剩餘熱量
   - 蛋白質
   - 碳水
   - 脂肪
   - 蔬菜
   - 飽足度

5. **舊會員自動套用新版公式**
   - 開啟頁面時會重新核對目前目標公式；若舊版目標不同，會自動更新每日熱量與三大營養素，不需重新建立帳號。
