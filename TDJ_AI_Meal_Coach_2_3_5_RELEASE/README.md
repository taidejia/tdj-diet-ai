# TDJ AI 餐盤教練 2.3.5 RELEASE

基底：2.3.4 RELEASE。

本版只補強「多張照片逐張辨識後再合併」流程，不重寫其他已定案功能。

## 2.3.5 多圖逐張分析補強
- 多張照片上傳時，系統會先把每一張照片獨立送入模型預讀，再進行整餐合併判斷。
- 每張照片都會先分類為食物本體、營養標示、包裝／成分表、混合內容或不清楚。
- 每張照片若有營養標示，會獨立嘗試讀取每份量、每包份數、熱量、蛋白質、碳水、脂肪與膳食纖維。
- 最終合併時才判斷「同一產品／同一盤的不同角度」並去重；無法確認相同時，不得自行忽略。
- 同一產品的食物照＋營養標示只計一次；不同產品則分別納入整餐。
- 加入 images_accounted_for 與 image_merge_note，讓後端可以檢查最終合併是否有逐張納入。
- 單張照片流程維持原本方式，不增加額外預讀請求。
- 保留 2.3.4 的多語言營養標示辨識、2.3.3 初始設定、身體反應、168、照片留存、顧問分權等既有功能。
