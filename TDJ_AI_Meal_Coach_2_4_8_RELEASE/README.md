## 2.4.6 脂肪判斷優化
- 單餐脂肪較高不再直接等同於「吃得太油」。
- AI 區分食物本身脂肪、烹調油脂、混合與無法確定。
- 鯖魚、鮭魚、蛋、堅果等食材脂肪不再自動被描述為烹調過油。
- 只有炸物、麻油、三杯、明顯油煎/大量炒油或濃厚油醬等有足夠證據時，才提示烹調油脂。
- 全天脂肪累積判斷維持原有每日目標邏輯。


## 2.4.7 後台逐日飲水紀錄
- 學員詳情的每日下拉紀錄同步顯示當日實際飲水量 / 每日目標與達成率。
- 即使某一天沒有餐點、只有飲水紀錄，該日期仍會保留在每日紀錄中。
- 7/14/21/30 天篩選會同步限制逐日飲水資料範圍。
